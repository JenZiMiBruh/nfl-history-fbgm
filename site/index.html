03Why this exists

Basketball GM had history. Football GM didn't.

I've played Football GM since 2020. Basketball GM is what got me into NBA history: real players, real ratings, logos and jerseys going back decades. Start in 1985 and see if you'd have drafted Jordan.

Football GM didn't have any of that, so I built it. Every NFL season since 1966, rebuilt from real data. See if the Patriots can really go 19-0. See what happens if Barry Sanders doesn't retire.

— JenZiMiBruh
